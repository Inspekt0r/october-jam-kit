# Предложение по врагам и боссу

Статус: базовый патрульный противник ближнего боя уже реализован; его фактические настройки и подключение графики — в `enemy-guide.md`. Стрелок и босс ниже остаются планом следующего этапа. Числа — стартовые значения для настройки.

## Общие правила боя

- У каждой опасной атаки три видимые стадии: **подготовка → активная атака → восстановление**.
- Урон наносит область попадания во время активной стадии. Изменение анимации и цвета помогает прочитать момент атаки.
- Герой после попадания получает короткую неуязвимость; повторный контакт не должен мгновенно снимать всё здоровье.
- Враги останавливаются при карте, паузе и переходе. Смерть героя сбрасывает текущий бой.
- Для первого варианта достаточно удара героя J и прыжка. Уклонение и комбо можно добавить после настройки этих действий.

## Враг 1: патрульный страж

Задача — научить подходить на дистанцию, ждать замаха и атаковать в окно восстановления.

| Параметр | Начальное значение |
|---|---:|
| Здоровье | 3 |
| Скорость патруля | 1.5 ед./с |
| Дистанция обнаружения | 5 ед. с прямой видимостью |
| Дистанция удара | 1.2 ед. |
| Подготовка | 0.45 с |
| Активная стадия | 0.15 с |
| Восстановление | 0.7 с |
| Урон | 1 |

Состояния: патруль → обнаружение → подход → подготовка → удар → восстановление. При потере видимости враг возвращается в область патруля. Перед краем платформы или стеной разворачивается. После начала замаха фиксирует направление, чтобы герой мог перепрыгнуть за спину. Урон наносится оружием, а касание тела можно оставить безопасным: так первая проверка боя будет понятнее.

## Враг 2: стрелок с платформы — после стража

Задача — заставить использовать прыжок и платформы. Стоит на месте, смотрит на героя, показывает направление выстрела 0.6 секунды, выпускает один медленный снаряд и восстанавливается 1.2 секунды. Снаряд летит без наведения и исчезает при встрече со стеной. Стрелок имеет 2 здоровья. Сначала настраивается отдельно, затем комбинируется со стражем; одновременно вводить оба типа в первую боевую комнату не стоит.

## Первый босс: хранитель прохода

Одна арена, 16 здоровья, урон каждой атаки 1. Для первого варианта достаточно двух атак и изменения темпа на половине здоровья.

**Рывок.** Подготовка 0.7 секунды с указанием направления. Босс фиксирует направление, делает рывок вдоль пола до заданного расстояния или стены. Герой перепрыгивает его. Восстановление 1 секунда даёт возможность нанести 1–2 удара.

**Удар по земле.** Подготовка 0.8 секунды с заметным поднятием корпуса/оружия. Короткая ударная область рядом с боссом; затем две низкие волны уходят по полу. Герой отходит от прямого удара и перепрыгивает волну. Восстановление 1.1 секунды.

При здоровье ≤8 босс немного сокращает восстановление, например на 20%, и чередует две атаки быстрее. Новые непрочитанные удары и внезапное увеличение урона для первой версии не нужны.

Арена должна оставлять место для прыжка и разворота; враг не должен зажимать героя без безопасного выхода. Бой начинается только после входа в отдельный триггер. На время боя двери можно закрыть явными воротами. При смерти героя босс возвращается в исходное состояние; после победы ворота открываются.

## Что запоминать при бэктрекинге

Предлагаю разные правила: обычные враги восстанавливаются при новом входе в комнату, а победа над боссом сохраняется. Для этого потребуется добавить в WorldProgress стабильные флаги, например `boss_guardian_defeated`, и отдельный ID экземпляра босса. Текущий WorldProgress хранит только посещённые комнаты — эти флаги ещё предстоит реализовать.

## Порядок реализации

1. Настроить существующий удар на мишени: дистанция, подготовка, активное время, интервал.
2. Добавить одного стража и проверить бой без ловушек и переходов.
3. Добавить явную реакцию на урон: вспышку, небольшой толчок и звук.
4. Собрать отдельную арену и одну атаку босса — рывок. После проверки добавить удар по земле.
5. Подключить ворота, сброс боя после смерти и сохранение победы.
6. Проверить бой после возврата в комнату и при открытии карты в каждой стадии атаки.
