# Комнаты, бэктрекинг и карта

## Готовый пример

Нажми Explore world в главном меню. Три комнаты образуют цикл: Crossroads ↔ Gallery ↔ Upper Passage ↔ Crossroads. Синие зоны по краям — выходы; вход в них автоматически переносит в соседнюю комнату. Герой появляется у связанного входа с безопасным отступом от выхода, поэтому можно сразу идти обратно.

Переходы загружают следующую сцену асинхронно через короткое затемнение без меню или экрана результатов. Это отдельные сцены комнат, а не единая непрерывно загруженная сцена. Одновременно загружена одна комната. Объект героя сохраняется между переходами вместе со своими текущими параметрами; камера подключается к нему в новой комнате.

Tab открывает и закрывает карту; Esc и Close map также закрывают её. При открытой карте физика стоит на паузе. В меню Tab по-прежнему переключает элементы интерфейса.

Карта показывает целиком каждую посещённую комнату, связи между уже посещёнными комнатами, выделение текущей комнаты и белую точку положения героя. Неисследованные комнаты и связи с ними скрыты. Открытие комнаты записывается в PlayerPrefs. Это сохранение исследования, а не сохранение положения, предметов или состояния врагов.

## Где редактировать

- `Assets/JamKit/WorldDemo/Scenes/` — три демонстрационные сцены.
- `Assets/Resources/WorldDefinition.asset` — список комнат, стабильные ID, имена сцен, подписи и прямоугольники комнат на карте; список Links задаёт визуальные связи.
- Объект Room Settings в каждой комнате → WorldRoom: Room Id, Player Prefab, Default Spawn, Entrances и World Bounds.
- `Assets/JamKit/Generated/Player.prefab` — общий герой этих комнат. Он создаётся при запуске, поэтому не виден в Hierarchy комнаты до Play. Меняй параметры на префабе, чтобы они применялись во всех трёх комнатах.
- Объекты West exit / East exit → RoomDoor: Destination Room — ID комнаты, Destination Entrance — ID входа в ней.
- Runtime/WorldMapView.cs — оформление карты; интерфейс карты создаётся при запуске и появляется под JamKitApp → World Map UI.

Старый Sandbox оставлен для экспериментов и регрессионной проверки. Его отдельный Player не связан автоматически с общим префабом героя.

## Добавление своей комнаты

1. Скопируй одну сцену WorldDemo через Save As с уникальным именем и добавь её включённой в Build Profiles → Scene List.
2. На WorldRoom задай уникальный Room Id. Удали копию героя из сцены, если добавлял её вручную: общий Player Prefab создаётся приложением.
3. Создай безопасный Default Spawn. В Entrances добавь ID входов и Transform точек появления. Например: `from_hub`. Точки должны лежать внутри комнаты, вне коллайдеров дверей и опасностей.
4. Добавь комнату в WorldDefinition: тот же ID, имя сцены, название и Map Bounds. Map Bounds — положение и размер прямоугольника на схеме, не мировые координаты сцены. WorldRoom.World Bounds — мировые границы комнаты для отметки положения героя.
5. У выхода поставь BoxCollider2D с Is Trigger и RoomDoor. Укажи ID соседней комнаты и ID её входа. Для обратного пути создай отдельную дверь в соседней сцене.
6. Добавь пару комнат в WorldDefinition.Links, чтобы связь появилась на карте после посещения обеих комнат. Эта связь описывает схему; реальные переходы задают RoomDoor.
7. Настрой CameraFollow.min/max: границы центра камеры. Target назначится автоматически.

Сохраняй ID комнаты стабильным: он используется для открытия карты и запоминания чекпоинта. Имена входов должны совпадать точно. При ошибке назначения дверь выдаст сообщение в Console.

## Чекпоинты и перезапуск

Зелёный чекпоинт запоминается для своей комнаты в текущей сессии. После ухода и возвращения герой появится у входа, а при смерти вернётся к ранее активированному чекпоинту этой комнаты. Пока чекпоинт не активирован, безопасной точкой служит использованный вход.

R перезапускает текущую комнату и сбрасывает её чекпоинт. Возврат в меню завершает сессию и сбрасывает чекпоинты всех комнат. Исследованная карта остаётся открытой.

## Восстановление примера и проверка

Jam Kit → Add connected world demo добавляет отсутствующие демонстрационные сцены и регистрирует их в сборке. Существующие комнаты и WorldDefinition не перезаписываются. Исходный Generate starter scenes создаёт старый шаблон и меняет Play Scene обратно на Sandbox; после него при необходимости снова вызови Add connected world demo.

Windows: `JamKit.exe --world-smoke -batchmode -logFile world-smoke.log`. Проверка охватывает переходы в обе стороны, немедленный возврат, отсутствие дубликатов героя, чекпоинты, сохранение исследования, Tab/Esc и скрытие неизвестных комнат. Результат — QA/world-result.txt рядом с exe. Без -batchmode создаются скриншоты карты. Проверка временно изолирует данные исследования и восстанавливает их после завершения.
