# Настраиваемый противник ближнего боя

## Где посмотреть и как добавить

Открой **Assets/JamKit/Enemies/EnemyDemo.unity** и нажми Play. Герой начинает слева, противник патрулирует справа. Это отдельная техническая сцена; существующие комнаты мира не менялись.

Для своей комнаты перетащи **Assets/JamKit/Models/Enemy.prefab** на безопасную поверхность. Корневой Transform оставь в масштабе 1, без поворота. Враг высотой 1.2 стоит центром примерно на 0.6 выше поверхности. Земле нужен слой Ground, врагу — слой 8 (Damageable), герою — слой 7 (Player).

Команда Jam Kit → Add melee enemy создаёт отсутствующие профиль, префаб, Animator и демонстрационную сцену; существующие файлы не перезаписывает. EnemyDemo включена в Scene List для проверок, но главное меню по-прежнему запускает обычный мир. Чтобы начинать с неё, временно укажи GameApp.Play Scene=EnemyDemo либо запускай её непосредственно в редакторе.

## Один профиль на тип врага

На корне префаба **EnemyBrain → Definition** назначен `Assets/JamKit/Enemies/BasicEnemy.asset`. Все экземпляры с этой ссылкой используют один набор параметров. Для другого типа сделай Duplicate профиля и назначь копию; при необходимости создай Prefab Variant врага. EnemyPresentation автоматически берёт этот профиль у EnemyBrain при запуске.

| Настройка | По умолчанию | Назначение |
|---|---:|---|
| Max Health | 3 | Запас здоровья; задаётся здесь, Health инициализируется из профиля |
| Patrol Speed | 1.5 | Скорость патрулирования |
| Chase Speed | 2.5 | Скорость подхода к герою |
| Patrol Distance | 3 | Расстояние влево/вправо от начального положения; 0 — стоять |
| Detection Range | 5 | Радиус обнаружения; стена Ground перекрывает видимость |
| Lose Sight Delay | 1.2 с | Время движения к последней видимой позиции после потери героя |
| Damage | 1 | Урон удара |
| Attack Reach / Height | 1.1 / 1.25 | Ширина и высота области попадания перед врагом |
| Windup | 0.45 с | Подготовка с зафиксированным направлением |
| Active Time | 0.15 с | Активная область удара |
| Recovery | 0.7 с | Восстановление после удара |

Враг не прыгает и не строит путь по платформам: он ходит по своей поверхности, разворачивается перед стеной или обрывом, подходит к видимому герою. Если герой выше/ниже, враг может остановиться под ним, но не атакует через перекрывающую стену. На карте и в паузе поведение и таймеры останавливаются.

Во время замаха направление фиксируется: герой может отойти или перепрыгнуть за спину. Одна цель получает не более одного попадания за взмах даже без неуязвимости игрока. Само тело врага не наносит контактный урон. При смерти коллайдер и движение сразу отключаются, затем проигрывается оформление смерти и объект удаляется. При повторной загрузке комнаты обычный враг появляется заново; сохранения его поражения пока нет.

С выделенным врагом и включёнными Gizmos видны радиус обнаружения, область патруля и зона удара.

## Спрайты без анимации

В профиле есть **Idle / Walk / Windup / Attack / Death Sprite**. Заполни нужные состояния. Пустое поле использует исходный спрайт модели — общий ArtTheme.Enemy или локальный Override Sprite на Visual → SpriteStyle. Физический коллайдер остаётся прежним.

**Use State Tint** включает технические подсказки цветом: жёлтый замах, красная активная атака, затемнение смерти. После подключения полноценной графики можно отключить эти оттенки.

## Покадровая анимация

В `Assets/JamKit/Enemies/Animations` подготовлены клипы-заготовки, а `BasicEnemy.controller` содержит состояния:

`Idle`, `Walk`, `Windup`, `Attack`, `Recovery`, `Hurt`, `Death`.

Кадров персонажа в этих клипах пока нет — они оставляют видимой статическую заглушку. Для наполнения:

1. Импортируй лист спрайтов как Sprite (2D and UI), Sprite Mode=Multiple и нарежь кадры в Sprite Editor.
2. Открой префаб Enemy, выбери дочерний Visual с Animator и открой Window → Animation → Animation.
3. Выбери, например, Walk и добавь кадры в дорожку **SpriteRenderer.Sprite**. Аналогично заполни остальные клипы. Альтернатива — назначить свои клипы в Motion соответствующих состояний контроллера.
4. Idle/Walk зациклены; Attack/Death обычно оставляют без Loop Time. Используй одинаковые размеры кадров, Pivot и Pixels Per Unit, чтобы персонаж не прыгал по размеру.
5. Подгони длительности Windup, Active Time, Recovery, Hurt Duration и Death Duration под клипы. Время урона задаёт логика, а не Animation Events.

Можно назначить собственный Animator Controller в профиле и указать другие имена состояний. В коде поддерживаются пути вида `Locomotion.Walk`; имя базового слоя добавляется автоматически. Путь состояния учитывает слой, как описано в [документации Animator](https://docs.unity3d.com/ScriptReference/Animator.Play.html). Отсутствующее состояние пропускается без ошибки: статические спрайты и поведение продолжают работать.

Переходы между состояниями запускает EnemyPresentation. Безусловные переходы Any State в пользовательском контроллере могут перебить его команды. Анимируй Visual, а не корневой Rigidbody2D; Apply Root Motion выключен. Hurt — краткая визуальная реакция, она не оглушает ИИ и не прерывает расчёт текущей атаки. Теперь она сопровождается миганием; настройки и подключение анимации героя описаны в [реакции на урон](damage-feedback.md).

## Звуки

В BasicEnemy можно отдельно назначить **Footstep / Alert / Windup / Attack / Hurt / Death Sound**. Пустые поля означают тишину, тестового гула нет.

- Footstep Interval — интервал шагов при движении.
- Volume — громкость конкретного типа врага.
- Общие Effects Volume и Master Volume применяются через настройки игры.
- Все звуки сейчас 2D, без затухания по расстоянию.
- Объект живёт после смерти не меньше Death Duration и длины Death Sound, чтобы звук не обрывался. Для длинного клипа смерти укажи достаточную Death Duration.

## Атака героя мышью

Теперь атакуют **ЛКМ и J**. Удержание не создаёт автоматическую серию: требуется новое нажатие после интервала атаки. Клик по Resume и удерживаемая после меню/карты кнопка не запускают случайный удар — сначала её нужно отпустить. Атака остаётся направленной в последнюю сторону движения героя, а не в курсор.

## Проверка

`JamKit.exe --enemy-smoke -batchmode -logFile enemy-smoke.log` проверяет патруль, стену, край, обнаружение, подготовку, уклонение, урон, паузу, Animator, смерть и ЛКМ/J. Результат — QA/enemy-result.txt рядом с exe. Без -batchmode сохраняется скриншот. Прежние проверки Sandbox, мира и мишени остаются доступными.
