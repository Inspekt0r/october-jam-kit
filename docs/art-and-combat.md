# Оформление, здоровье и атака героя

## Общее оформление

Открой **Assets/Resources/ArtTheme.asset**. Перетащи импортированные спрайты в нужные поля:

- Background — фон игровых комнат.
- Wall — пол и стены.
- Platform — платформы в воздухе.
- Player — изображение героя в мире.
- Enemy / Boss — изображения моделей врага и босса.
- Door — внешний вид входов/выходов; направления задаются RoomDoor, а не изображением.
- Checkpoint / Hazard — чекпоинт и опасность.
- Player Portrait — отдельный портрет в HUD. Если поле пустое, используется Player; без спрайтов показывается цветная заглушка.
- Enemy Portrait — резерв под будущий интерфейс врага, пока нигде не выводится.
- Health Full / Health Empty — изображения полной/пустой единицы здоровья; без спрайтов используются цветные квадраты.

Импорт PNG: выдели файл в Project → Texture Type **Sprite (2D and UI)** → Sprite Mode **Single** → Apply. Для пиксель-арта можно выбрать Filter Mode **Point** и Compression **None**. Одинаковый Pixels Per Unit упрощает работу с набором графики. Листы анимаций режутся через Sprite Editor; у функционального Enemy.prefab уже есть Animator с заготовками состояний — см. `docs/enemy-guide.md`.

Пустые поля темы оставляют цветные технические заглушки. Готовая графика не генерировалась.

## Локальные отличия

У модели есть корневой объект с физикой и дочерний **Visual → SpriteStyle**:

- Role выбирает поле из ArtTheme.
- Override Sprite заменяет картинку только этого объекта.
- Size задаёт прямоугольник изображения в локальных единицах родителя.
- Tint окрашивает назначенный спрайт; Placeholder Color — заглушку.
- Sorting Order определяет порядок рисования: фон -100, объекты 0, герой 10.

Спрайт растягивается под заданный Size. Для сохранения пропорций задай отношение ширины и высоты соответственно исходной картинке. Стены пока не собираются автоматически из тайлов: для повторяющихся рисунков можно затем использовать Tilemap или вручную разложить модели.

Меняй SpriteStyle, а не его Transform Scale и SpriteRenderer.Sprite: при обновлении темы компонент снова применит свои значения. Физический размер задаётся отдельно на корневом BoxCollider2D. Фон не имеет коллайдера. Для индивидуального фона комнаты выбери Room Background → Visual и задай Override Sprite.

После изменения префаба модели обновятся связанные экземпляры. Объекты старых WorldDemo сцен сохраняют свою геометрию и настройки; их графика связана с общей темой через SpriteStyle.

## Герой и HUD

Общий герой мира: **Assets/JamKit/Generated/Player.prefab**.

- PlayerMotor — движение и прыжок; Avatar ссылается на видимый SpriteRenderer.
- Health.Max Health — максимум здоровья, по умолчанию 5.
- Health.Invulnerability Seconds — защита от повторного урона, по умолчанию 0.7 секунды.
- PlayerVitals связывает смерть с возвращением к чекпоинту.
- PlayerAttack — параметры удара.

В HUD отображаются портрет, единицы здоровья и точное число `HP 4/5`. До 10 единиц показываются отдельными значками, большее значение остаётся видимым числом. Изображения значков и портрет задаются темой. Расположение HUD — Runtime/PlayerHud.cs; во время Play его объекты видны в JamKitApp → Player status UI.

Здоровье сохраняется при переходах между комнатами. Смерть и падение возвращают к чекпоинту и восстанавливают здоровье. Перезапуск комнаты начинает её с полным здоровьем. Положение и здоровье между закрытием и новым запуском приложения пока не сохраняются.

Старый RoomTrigger.Hazard — мгновенное возрождение, а новый DamageZone снимает здоровье. В Gallery добавлена красная тренировочная DamageZone; урон задаётся полем Damage.

## Ближний удар

Клавиша **J или ЛКМ**. Удар направлен в последнюю сторону движения и работает на земле и в воздухе. На PlayerAttack настраиваются:

| Поле | По умолчанию | Значение |
|---|---:|---|
| Damage | 1 | Урон за одно попадание |
| Reach | 1.35 | Дальность перед краем коллайдера героя |
| Height | 1.1 | Высота области попадания |
| Windup | 0.06 с | Подготовка |
| Active Time | 0.1 с | Время проверки попаданий |
| Cooldown | 0.35 с | Минимальное время между атаками |
| Target Mask | слой 8 | Слои целей |
| Wall Mask | Ground | Стены, блокирующие попадание |
| Attack Sprite | заглушка | Картинка короткого эффекта удара |

Одна цель получает урон не более одного раза за взмах. Стена между героем и целью блокирует удар. В паузе, на карте и во время перехода атаки отключены. Эффект — техническая визуализация зоны попадания; полноценной анимации оружия и отбрасывания пока нет.

В Gallery стоит **Training target**. У неё 3 здоровья; после трёх обычных ударов она исчезает на 2 секунды и восстанавливается. Это мишень для настройки дистанции и скорости атаки, без поведения врага. Для своей цели нужны Health, коллайдер и слой из Target Mask; реакцию на Died задаёт отдельный компонент.

## Статус врагов и босса

EnemyVisual и BossVisual — сменные модели без поведения. Дополнительно создан функциональный Enemy.prefab: патруль, обнаружение, подход, ближняя атака и смерть. Его настройка описана в `docs/enemy-guide.md`. Стрелок и босс остаются предложениями из `docs/enemies-and-boss-design.md`.
