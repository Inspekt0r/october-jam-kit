# Как строить комнаты и связывать их

Работай вне Play Mode: значения, изменённые во время игры, Unity обычно откатывает. Сохраняй сцены Ctrl+S, а изменения префабов — через Prefab Mode или Overrides → Apply, если их нужно распространить на все экземпляры.

## 1. Создай комнату

В Unity выбери **Jam Kit → Create empty world room** и сохрани сцену, например `Assets/MyGame/Scenes/Cave01.unity`. Команда создаёт сцену из `Assets/JamKit/Models/RoomTemplate.prefab`: фон, пол, платформу, камеру, точки появления и две двери. Существующую сцену WorldDemo также можно скопировать через File → Save As.

В Hierarchy выбери корень RoomTemplate и компонент **WorldRoom**:

- **Room Id**: стабильный уникальный ID, например `cave_01`. Это ключ комнаты для карты и чекпоинтов.
- **Player Prefab**: общий `Assets/JamKit/Generated/Player.prefab`. Герой создаётся автоматически; добавлять второго героя на сцену не нужно.
- **Default Spawn**: Transform безопасного стартового появления.
- **Entrances**: список именованных входов с Transform точек появления. В шаблоне уже есть `west` и `east`.
- **World Bounds**: мировые координаты границ комнаты для точки героя на карте. Например X=-13, Y=-2.5, W=26, H=8.

Оставь корень шаблона в позиции (0,0,0), масштабе (1,1,1), без поворота. Перемещай геометрию и точки внутри него. Пол находится на Y=-2 с высотой 1; для героя высотой 1.2 безопасный центр появления около Y=-0.85. Точка входа должна находиться внутри комнаты, вне дверного триггера, стен и опасностей.

## 2. Построй геометрию

Перетаскивай префабы из `Assets/JamKit/Models`:

| Префаб | Для чего | Что редактировать |
|---|---|---|
| Background | Фон без столкновений | Visual → SpriteStyle; Position и Size |
| Wall | Пол, стены, потолок | Корневой BoxCollider2D и Visual → SpriteStyle |
| Platform | Платформа в воздухе | Position, BoxCollider2D.Size и SpriteStyle.Size |
| Door | Зона перехода | RoomDoor, BoxCollider2D.Is Trigger, Visual |
| DamageZone | Ловушка с уроном здоровью | Damage, размер триггера и Visual |
| TrainingDummy | Мишень для проверки удара | Health, Reset After и Visual |
| EnemyVisual / BossVisual | Заготовка внешнего вида | Только Visual; поведения врага пока нет |
| Enemy | Противник ближнего боя | Патруль, обнаружение, атака и смерть; профиль BasicEnemy |
| Story/NPC | Персонаж или читаемый объект | E открывает назначенный диалог |
| Story/StoryTrigger | Сюжетная область | Автоматический рассказ при входе героя |

У пола, стен и платформ должен быть слой **Ground**. Он нужен и столкновениям, и проверке приземления, и блокированию удара через стену. Обычная Platform — твёрдая с обеих сторон. Односторонние платформы пока не настроены.

У новых моделей корневой Transform лучше оставлять в масштабе 1. Меняй **BoxCollider2D.Size** для физического размера, а **Visual → SpriteStyle.Size** — для размера изображения. У старых объектов WorldDemo размер также задан масштабом корня, поэтому SpriteStyle.Size=1 там нормален. Включи Gizmos, чтобы видеть реальные границы коллайдеров.

Изображение и коллайдер разделены намеренно: длинное оружие, волосы или декорации на спрайте не должны автоматически менять физику героя.

## 3. Настрой камеру

В шаблоне уже есть Camera и CameraFollow:

- **Orthographic Size** — половина видимой высоты мира.
- **Offset** — смещение относительно героя.
- **Min / Max** — допустимые координаты центра камеры, а не внешних краёв комнаты.
- **Smooth Time** — плавность следования.
- **Target** назначается автоматически при входе в комнату.

Для камеры высотой 11 единиц (Orthographic Size=5.5) в комнате от X=-13 до X=13 при экране 16:9 допустимый центр примерно от X=-3 до X=3. Увеличивая комнату, увеличь фон и проверь, чтобы за краями изображения не появлялся цвет очистки камеры.

## 4. Зарегистрируй сцену и карту

Открой **File → Build Profiles → Scene List**, добавь Cave01 и включи галочку. Имя сцены должно быть уникальным среди сцен сборки.

Открой `Assets/Resources/WorldDefinition.asset`, увеличь массив Rooms и заполни:

| Поле | Пример |
|---|---|
| Id | `cave_01` — точно как WorldRoom.Room Id |
| Scene Name | `Cave01` — имя файла сцены без `.unity` |
| Title | `Старая пещера` — подпись на карте |
| Map Bounds | X=440, Y=0, W=180, H=100 |

Map Bounds — положение прямоугольника на схеме, а World Bounds — координаты внутри игровой сцены. Это разные величины. На схеме положительный Y направлен вверх. Прямоугольники комнат не должны перекрываться. Комната откроется целиком после первого посещения.

## 5. Свяжи две комнаты в обе стороны

Создай Cave02 тем же способом и задай Room Id=`cave_02`. В каждой комнате оставь входы `west` и `east`.

| Где стоит дверь | Destination Room | Destination Entrance | Куда появится герой |
|---|---|---|---|
| Восточный выход Cave01 | `cave_02` | `west` | У западного входа Cave02 |
| Западный выход Cave02 | `cave_01` | `east` | У восточного входа Cave01 |

В поле Destination Room пишется **ID комнаты**, а не имя сцены. Destination Entrance должен точно совпадать с одним из ID массива Entrances комнаты назначения. `west` и `east` — условные имена, можно использовать `from_hub`, `upper_tunnel` и другие.

Дверь — обычный **BoxCollider2D с Is Trigger**, а герой — Rigidbody2D с коллайдером. Поставь триггер на пути героя и сделай достаточно высоким, чтобы прыжком нельзя было случайно обойти выход. Точку появления в соседней комнате отодвинь внутрь от её выходного триггера. В шаблоне выход около X=±12.5, вход около X=±10.

В WorldDefinition.Links добавь **одну** пару From=`cave_01`, To=`cave_02`. Links рисует линию на карте и не создаёт переход. Реальные переходы задаются дверями; для двусторонней связи нужны обе строки из таблицы выше.

Неиспользуемые двери отключи или удали. Для тупика можно оставить одну дверь обратно. Для дополнительного ответвления добавь новый экземпляр Door и новый вход в соседней комнате.

## 6. Сделай комнату стартовой

В `Assets/Resources/JamKitApp.prefab` выбери корневой GameApp и укажи **Play Scene=Cave01**. Главное меню остаётся первой сценой в Scene List. Кнопка Explore world теперь начнёт прохождение с Cave01.

## 7. Проверь вручную

1. Запусти главное меню, войди в Cave01.
2. Пройди в Cave02 и сразу вернись: герой должен появиться у правильного входа, без обратного переброса.
3. Нажми Tab до и после первого перехода: на карте должны открыться только посещённые комнаты, затем связь между ними.
4. Активируй чекпоинт, уйди и вернись. Появление — у входа, смерть — у запомненного чекпоинта этой комнаты.
5. Проверь фон по краям, прыжок на платформы, физические стенки, здоровье и удар J.
6. Собери Windows через Jam Kit → Build Windows и проверь всю папку сборки, а не только запуск сцены из редактора.

## Частые ошибки

| Симптом | Что проверить |
|---|---|
| Дверь не работает | Is Trigger, ID назначения в WorldDefinition, включённая сцена в Scene List |
| Появление не там | Destination Entrance и ссылка Point в комнате назначения |
| На карте нет линии | WorldDefinition.Links и посещение обеих комнат |
| На карте герой смещён | WorldRoom.World Bounds; это не Map Bounds |
| Герой проваливается или не прыгает | BoxCollider2D, слой Ground, Ground Mask у PlayerMotor |
| Два героя или две камеры | Удали лишнюю копию; в WorldRoom герой создаётся из Player Prefab |
| Спрайт изменился, физика осталась прежней | Это ожидаемо: настрой коллайдер отдельно |
| Параметры пропали после остановки | Они менялись в Play Mode; повтори вне игры |

Файлы сцены, префабы и соседние `.meta` нужно переносить вместе: ссылки между ними опираются на GUID из метафайлов.
