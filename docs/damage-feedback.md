# Реакция на получение урона

Герой и противники мигают после успешного несмертельного попадания: примерно 0.35 секунды, с переключением видимости каждые 0.06 секунды. Повторное попадание запускает эффект заново. Заблокированный урон и попадание во время неуязвимости не запускают его.

Эффект не меняет цвет, спрайт или физику. На паузе и карте его время останавливается. При смерти враг становится видимым для анимации смерти; при возрождении героя эффект сбрасывается. Мигание само по себе не добавляет неуязвимость, отбрасывание или оглушение.

## Герой

Выбери `Assets/JamKit/Generated/Player.prefab` → корень → **Player Vitals → Damage Feedback**:

- **Flash On Hurt** — включить мигание.
- **Hurt Duration** — общая длительность.
- **Hurt Blink Interval** — время между переключениями видимости.
- **Hurt Animator** и **Hurt Trigger** — необязательная полноценная анимация.

В Sandbox герой является объектом сцены: те же параметры меняй на Player в Hierarchy. В связанных комнатах используется общий префаб.

Для будущей анимации добавь Animator на Visual героя, назначь его в Hurt Animator и создай Trigger с именем `Hurt`. В своём контроллере настрой переход по этому триггеру в состояние Hurt, а выход — по окончании клипа. Код запускает триггер только при наличии такого параметра. Самих кадров анимации пока нет. Чтобы показывать анимацию без исчезновения персонажа, выключи Flash On Hurt.

## Враги

Открой `Assets/JamKit/Enemies/BasicEnemy.asset` или профиль другого типа врага:

- **Flash On Hurt**, **Hurt Duration**, **Hurt Blink Interval** управляют миганием.
- **Hurt State** задаёт имя состояния Animator; по умолчанию `Hurt`.
- **Hurt Sound** — звук попадания.

В `Assets/JamKit/Enemies/Animations/Hurt.anim` можно добавить кадры SpriteRenderer.Sprite или заменить Motion состояния Hurt своим клипом. Подгони Hurt Duration под длину реакции. Состояние Hurt сохраняет приоритет на это время, затем возвращается анимация текущего поведения; смерть сразу прерывает реакцию. Это визуальная реакция: расчёт движения и атаки врага продолжается.

Компонент DamageFlash подключается автоматически при запуске. Его вручную добавлять не требуется. Он воздействует на основной SpriteRenderer персонажа; для персонажей из нескольких отдельных спрайтов нужно расширить список рендереров.

Проверка: `Builds/Windows/JamKit.exe --enemy-smoke -batchmode -logFile feedback-smoke.log`. В неё включены мигание обоих персонажей, восстановление видимости, пауза, Hurt и отмена эффекта при смерти/возрождении.
